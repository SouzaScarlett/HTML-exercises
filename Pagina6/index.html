Perguntas Frequentes (FAQ)

Clique nas perguntas para ver as respostas.

Como faço para baixar os exercícios?

Você pode clonar o repositório diretamente do GitHub ou baixar o arquivo .zip na página principal do projeto.

Quais tecnologias foram usadas?

Este projeto foi desenvolvido utilizando HTML5 para a estrutura e CSS3 para toda a estilização e animações.

O site é responsivo?

Sim! Utilizamos técnicas de Flexbox e CSS Grid para garantir que o conteúdo se ajuste a qualquer tamanho de tela.
